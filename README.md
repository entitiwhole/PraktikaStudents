# Практика.ПРО

[![Открыть сайт](https://img.shields.io/badge/🌐_Открыть_сайт-Praktika.PRO-2563EB?style=for-the-badge)](https://entitiwhole.github.io/PraktikaStudents/)

**Демо:** https://entitiwhole.github.io/PraktikaStudents/

Веб-сервис для поиска производственной практики студентами СПО и подбора
кандидатов учебными заведениями и предприятиями.

Проект представляет собой одностраничное приложение на React + TypeScript,
собранное на Vite и оформленное с помощью Tailwind CSS. Работает полностью в
браузере: данные демонстрационные, аккаунты и сессия хранятся в `localStorage`,
серверная часть не требуется.

## Возможности

- **Каталог предприятий** — карточки компаний, фильтры по отраслям, поиск и
  сортировка.
- **Страница предприятия** — описание, адрес, число мест, контакты и список
  подходящих специальностей.
- **Заявка на практику** — форма с автозаполнением данных студента, выбором
  предприятия и загрузкой резюме (drag & drop).
- **Статус заявки** — пошаговый трекер рассмотрения и история обращений.
- **Документы** — список файлов с предпросмотром PDF-заявки.
- **Личный кабинет** — профиль студента или сотрудника, настройки уведомлений,
  команда организации.
- **Кабинеты техникума и предприятия** — входящие заявки, статистика,
  одобрение и отклонение кандидатов.
- **Авторизация и регистрация** — вход по почте и паролю, выбор роли (студент /
  техникум / предприятие), код организации для сотрудников, запоминание сессии.
- **Тёмная тема, уведомления, модальные окна и адаптивная вёрстка.**

## Демо-доступ

На странице входа есть кнопки быстрого входа, а также можно войти вручную:

| Роль | Почта | Пароль |
| --- | --- | --- |
| Студент | `student@praktika.pro` | `student123` |
| Техникум | `college@praktika.pro` | `college123` |
| Предприятие | `company@praktika.pro` | `company123` |

Коды для регистрации сотрудников: `MTK-2025` — техникум, `YANDEX-2025` —
предприятие. Сотрудники, зарегистрированные с одним кодом, видны в профиле
в разделе «Команда».

> Это демонстрационная авторизация без сервера: пароли хранятся в `localStorage`
> в открытом виде. Для реального проекта нужен бэкенд и хэширование паролей.

## Быстрый старт

Требуется Node.js 20+ (рекомендуется 22) и pnpm или npm.

```bash
# Установка зависимостей
pnpm install   # или: npm install

# Запуск dev-сервера на http://localhost:5173
pnpm dev       # или: npm run dev

# Проверка типов
pnpm typecheck

# Production-сборка в папку dist/
pnpm build

# Локальный предпросмотр собранного приложения
pnpm preview
```

## Развёртывание

Проект собирается в статические файлы, поэтому подходит для любого
статического хостинга (GitHub Pages, Netlify, Vercel, nginx).

```bash
pnpm build
# содержимое dist/ можно выкладывать на хостинг
```

В `vite.config.ts` задан `base: "./"`, поэтому сборка работает и в корне
домена, и в подкаталоге без дополнительной настройки.
