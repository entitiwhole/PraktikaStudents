# Участие в проекте

Спасибо за интерес к «Практика.ПРО»!

## Как предложить изменения

1. Создайте форк репозитория и отдельную ветку от `main`:

   ```bash
   git checkout -b feature/краткое-описание
   ```

2. Установите зависимости и запустите dev-сервер:

   ```bash
   npm install
   npm run dev
   ```

3. Внесите изменения. Перед коммитом проверьте типы и сборку:

   ```bash
   npm run typecheck
   npm run build
   ```

4. Оформите коммит в повелительном наклонении, например
   `Add company filters` или `Fix mobile navigation`.
5. Откройте pull request в ветку `main` и опишите, что и зачем изменено.

## Стиль кода

- TypeScript без `any` там, где можно обойтись точным типом.
- Компоненты и функции — в `PascalCase` / `camelCase`, CSS-классы — в `kebab-case`.
- Стили — через классы Tailwind и переменные темы из `src/index.css`.
- Форматирование: `npm run format` (oxfmt).

## Сообщения об ошибках

Опишите шаги воспроизведения, ожидаемое и фактическое поведение, а также
браузер и версию Node.js.
